# BohdiAI — SHELVED (2026-09-04)

**This repository is archived and no longer actively developed.**

The BohdiAI name and domain (bohdiai.com) continue on a much simpler product built in Lovable — see the pivot notes below.

---

## What this repository was

An ambitious AI-powered SaaS platform for building storefronts. Built over ~85 development sessions from May–August 2026, it grew into a family/mood-driven storefront engine, Bohdi's multi-agent authoring crew, an in-app editor, a Make-It-Yours onboarding walk, and a full commerce roadmap.

Full picture of what was built and where things stood at shelving time: see `Project-Docs/SESSION-BRIEF.md` and `Project-Docs/Full-Plan.md`.

## What happened

The project's scope outgrew what one person could build and maintain solo. In September 2026 it was pivoted to a much simpler product — a $5/month mobile-first flyer + QR-checkout app for craft fair makers and social-drop sellers — built in Lovable rather than from scratch.

The new project keeps the BohdiAI name and domain but is a fundamentally different product with a fraction of the scope. It's not built in this codebase.
