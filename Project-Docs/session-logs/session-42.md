## Copywriter convergence — targeted retry on length-only failures

End of Session 41 had failed with `moment.story.0: 51 chars, max 48 — cut 3 characters`. The build retried 4 times with feedback and never converged because each retry was a full rewrite of every field; the model kept landing the same field at the same overshoot. Fix: when ALL validation failures are string length caps, the retry's tool_result now carries an explicit instruction: "Resubmit your previous draft EXACTLY as-is, changing only the fields listed in issues to fit their length. Every other field must be byte-for-byte identical. For each field being shortened: take the previous string and drop or shorten ONE word (or remove a small filler word like 'the', 'a', 'and'); do not write a new line from scratch — a fresh rewrite tends to land at the same length. Aim well under the cap, not right at it." On non-length failures (punctuation, missing field, wrong enum) the instruction is omitted — the model stays free to rewrite. New `isLengthOnly` + `buildResubmitPayload` helpers, used by both copywriter and cinematographer. Plus a soft prompt nudge: the moment.story directive now tells the model to AIM FOR 36-44 chars, with 48 framed as the hard cap that burns the build. Tests cover both branches.

## Standing lessons banked

Don't orphan authored content when refactoring a renderer. The hero story was being authored but never rendered — caught by Alex on the first live test ("why???"). When a refactor changes what renders, check what was authored that no longer has a home.

"Pick X when..., Pick Y when..." reads as equal options to the model. To preserve a bias like D47's "always reach for video," the criterion must STATE the default explicitly ("DEFAULT TO X. Only Y when..."). Phrasing the criterion in balanced-pick language stripped the video bias and the director defaulted to still on a baker. Same shape as the Standing Lessons item "Neutrality is not intent" but in a new register: bias loss isn't only from REMOVING examples, it's from REPHRASING the criterion as equal options.
