Real bug fixed (worth flagging for the port):
- Symptom: Clicking nav anchor links left header + h1 rendered at negative y coordinates (e.g., header at y=-214 with window.scrollY=0). Navbar and hero invisible after scrolling back to top.
- Root cause: `.scene` had `overflow: hidden`, which silently creates a scroll container in Chrome. When Chrome scrolled the anchor target into view, it scrolled `.scene` internally (not the document), permanently translating content upward.
- Fix: `overflow: clip` instead of `overflow: hidden` on `.scene`. `clip` provides the same visual clipping without creating a scroll container. CRITICAL: when porting to Next.js, any wrapper that's meant to clip atmospheric effects should use `overflow: clip`, not `overflow: hidden`. Document this in Engineering Standards or a component guide.
