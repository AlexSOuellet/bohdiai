- **Real bug fixed: Tailwind keyframe gotcha.** Keyframes declared in `theme.extend.keyframes` aren't emitted in the output CSS unless something uses the matching `animate-{name}` utility class in JSX. My `.build` (and `.scene-glow`, etc.) referenced keyframes via raw `animation:` inside `@layer components`, which Tailwind doesn't trace — so 6 keyframes silently went missing, leaving storefront content stuck at opacity 0. Fixed by declaring those keyframes directly in `globals.css`.
- 5 storefront-only fonts (UnifrakturCook, Bebas Neue, Fredoka, Caveat, Manrope) given `preload: false` so they don't block LCP.
