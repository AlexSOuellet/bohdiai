# Maker Checkup — Question Bank (draft for Alex's review)

**How it works:** these are the only questions the checkup can ask. The wording and choices below are fixed. After each answer, Haiku picks the most useful next question from this list (based on everything said so far) and writes one short reaction line above it. Nothing here is generated, so the same answers lead to the same questions.

**Everywhere:** tap questions also show the line *"Something else, or anything to add"* unless marked **(no extra line)**. "Pick all" questions say *"Pick every one that applies."*

**Must cover** (the checkup can't finish until these are answered): ★
